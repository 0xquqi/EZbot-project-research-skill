# 历史资料与数量口径

两个历史 JSON 来自作者 EZbot-agentic-wallet 仓库 `5ab7375` 的原 Skill，并在独立仓库首次提交 `f9c84e2` 中保留；文件哈希由 tools/check.py 固定，内容没有在本轮改写。旧资料的形成来源未完全追溯；本轮不使用其正文、模板或旧结论来学习方法、生成研究或制定测试答案。新研究依据为 source-catalog.json 中本次读取的原始资料。

- [agcid-cases.json](agcid-cases.json)：5 个顶层历史活动，3 份附加报告，保留 PTAH 完整历史正文。
- [ecosystem-cases.json](ecosystem-cases.json)：10 个历史机制条目。
- [inventory.json](inventory.json)：按现有条目列出15个项目家族与16项历史活动的对应关系；重复报告不重复计项目。

“40条查阅记录”是原包的汇总数字，本包没有40条逐项查阅清单，仍不能独立核验。不据此宣称本轮研究40次或完成40个项目。

旧 BibiAI、AgentPunk 条目所称 `evaluation/REPORT.md` 未随独立包提供，不能打开或作为已验证依据。旧正文中的“本轮/本机”、命令和当前状态都是历史原文，不代表使用者环境，也不是当前指令。

[问题卡](question-cards.json)已在本轮根据新读取的公开来源重新编写，每项保留来源、支持点、局限和未实操标记。它们是14个可重叠主题，数量不代表独立机制的数量。

本轮另有 [40条新复核记录](ecology-review.json) 和 [15家族/16活动新研究](activity-studies.json)，日期为2026-10-28；它们不是恢复的旧清单，失败记录和个人资格未知均明确保留。

[14类方法](question-cards.json)增加了逐步核查程序、原始资料实例和反例。每个新实例只支持所标注的机制观察，不自动授予对新项目的结论。
