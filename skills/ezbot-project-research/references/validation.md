# 本轮验证边界

本轮从公开官网、官方源码和标准重新建立依据，未读取两套被用户禁止的研究 Skill。原有暴露历史不能被抹除，不能宣称整份旧仓库从未参考过它们。

离线脚本测试检查解析行为，包括 SPA 链接、候选地址、精确 ABI、恶意文字、网络错误文本与大小限制。它们不测试模型语义准确率。

本轮人工使用网页工具、HTTP、真实浏览器和公开 RPC 研究公开案例，见 [case-studies.md](case-studies.md)。这是编写者参与的功能验证，有接触背景，不是独立盲测、跨模型评测或实盘认证。当前任意项目的个人资格、证明签名和交易执行仍需具体环境重新验证。

完整工具结果与执行命令记录在仓库 evaluation 目录；安装单独 Skill 时本页和案例摘要仍可阅读，不依赖该目录才能运行。

自动入口另验证了网址到规则/配置采集、文本到匹配源码/部署、固定区块标量读取，以及源码未收录时继续确认部署但保留缺口。部署匹配不自动证明当前个人可参与；复杂规则由宿主AI结合原文继续解释。
