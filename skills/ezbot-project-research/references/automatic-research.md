# 自动研究入口

用户给网址或铸造要求后，由宿主 AI 操作工具并完成解释。无需让用户先抓网页、找 ABI 或手工读源码。Python 工具负责取得和核对材料；宿主 AI 阅读原文、确定活动与地址角色并写出最终研究结果。

## 网址输入

从 Skill 目录运行，输出目录必须是新目录：

```bash
python3 scripts/research.py --url 'https://example.org/activity/#mint' --out /tmp/project-web-new
```

入口自动读取首页、跟进同站规则/指南链接，读取引用的配置或 ABI 脚本。默认最多4个页面、2个相关脚本，另受10次HTTP和100秒预算约束。保存原文、哈希、链接、候选地址与失败原因；不运行下载的 JavaScript。外站链接保留供 AI 判断，不自动信任或跟进。

接着阅读 `research-packet.json` 和相关原文。使用活动名称、官网地址表、实际选中网络和函数用途区分目标发行合约与市场/支付/身份地址。多目标时先按用户活动选择；没有足够依据才问用户，不取第一个地址。

如果是动态路由、挑战页面或静态材料不足，调用宿主浏览器打开原活动页，读取已渲染内容和页面实际引用的公开资源。需要登录/签名才能读取的部分交代缺口；不把读取失败译成项目关闭。

## 纯文本与链上输入

将用户原文保存为文本，AI 从明确线索提取链和目标地址。明确这些字段后可直接使用，不要求用户另提供活动网页：

```bash
python3 scripts/research.py --text-file requirements.txt --chain-id 56 --address 0x1111111111111111111111111111111111111111 --rpc-url https://bsc-rpc.publicnode.com --out /tmp/project-chain-new
```

上例地址只是占位符，执行时必须来自本轮输入或已核对的来源。用户只给合约时可以不传文本文件。网页研究已找到明确合约时，可单独调用同样的链入口继续；新输出与网页材料一起供 AI 阅读。

当前自动核验针对 EVM：使用 Sourcify v2 查询源码、ABI、签名和代理信息；RPC 先核对 chainId，再读取部署代码并与验证记录的运行代码比较。匹配且未识别代理后，最多读取6个与开放、供应、数量或价格相关的无参数标量 view/pure 函数。选择器来自同份验证记录，不从普通帖子猜测。仅用 eth_chainId、eth_getBlockByNumber、eth_getCode、eth_call，不支持发送或签名方法。

固定区块读取被服务以历史访问限制拒绝时，自动尝试 latest，同时保留原错误和实际 block_tag。任何这类回退或读取失败都会使“同一区块快照”不成立。不得把某个返回值直接转成个人可参与结论。

源码服务未收录时仍尝试确认目标链和部署是否存在，但不猜 ABI；AI 可通过公开浏览器或用户提供的当前源码继续核对，仍须区分资料声明与部署匹配。代理、动态返回、需钱包/数量参数的资格与报价，超出当前自动标量读取，由 AI 按已确认 ABI 选择宿主只读工具继续。缺钱包就不确认个人资格。

## 必须完成的用户结果

工具生成的是研究材料包，不是最终答案。AI 应按当前任务阅读函数实现、规则与状态，回答：

1. 目标活动与部署是什么，是否混有其他活动。
2. 当前发现的参与路径，每步入口、条件、输入、费用与产物。
3. 哪些条件有当前读取支持，哪些只是官方说明，哪些仍缺证。
4. 阻塞时明确原因，例如无当前 proof、未知钱包额度或依赖服务不可读。

不要把 collection-summary.md 或函数名列表直接当成研究完成。可以写本轮 `report.md` 并向用户交付简洁说明；前提不全时保留已查明路径与具体缺口。完整调用过但没有充分证据，也不能自动改走交易入口。

## 运行环境

辅助工具使用 Python 3.10+ 和系统 curl，无第三方 Python 包、模型 API 密钥或钱包依赖。抓取只接受公开 HTTP(S)，逐跳检查重定向，拒绝私有网络和凭证 URL，并固定本次解析到的公开地址。输出目录权限为0700；原始资料只在用户指定的本地目录保存，不自动写入仓库。宿主没有 Python/curl 时，AI 可用已有网页、浏览器与只读链工具完成同样的研究步骤。

此工具不包含独立大模型。自然语言解释与复杂源码推理由当前加载 Skill 的 AI 完成，自动化程序提供可核对的输入与只读结果。
