# 研究报告

根据任务规模精简，保留结论与证据之间的对应关系。

1. **项目与活动**：名称、官网、资产/产品/机制/阶段；链与部署版本。
2. **当前结论**：可参与、未开放、已结束/售罄、资格不满足、信息不足或读取失败；观察时间和区块。只在相关条件都已核实后说可参与。
3. **参与路径**：每步入口、前置条件、输入/单位、预期产物、等待或退款条件；读取、签名、交易分别注明。对未核实步骤显式断开路径。
4. **资格与费用**：身份/钱包限额、使用次数、数量语义、支付币种、本金/Gas/附加费/可退款部分；无具体钱包时避免断言个人资格。
5. **风险与未知**：与参与有关的管理员权限、代理升级、供应竞争、异步回调、签名与外部依赖。按证据说问题，不把“有源码”写成安全保证。
6. **证据表**：结论、URL 或链/地址/函数、读取时间/区块、证据类型、局限。区分官方描述、已匹配源码、当前读取、第三方线索和历史案例。
7. **下一步**：用户可跟随的官方页面操作或需要补齐的证据；研究结束不自动启动钱包操作。

仅在需要交给另一个执行系统时，附带非执行的说明：目标链/合约、函数签名、参数含义、支付规则、收件人证明、未决条件。不要输出未验证的 calldata 或把历史价格和地址作为默认值。执行方仍须实时核验并取得交易授权。
