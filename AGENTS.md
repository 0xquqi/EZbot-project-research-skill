# Development source boundary

For this repository, do not read, consult, learn from, or transfer `launch-project-research` or `alpha-research`, including their supporting files, scripts, templates, cases, remembered summaries, or derivative materials. This user boundary applies to all tools and agents taking over this project.

Use current user requirements, newly read public project originals, and official technical specifications. Existing archives and methods with unresolved origin are not independent learning sources. Keep historical artifacts for provenance inspection; do not use their bodies or formats to design new instructions, reports, or test answers.

Do not claim this project has never been exposed to those sources. New material must identify its actual public basis and actual test coverage. Changes do not authorize wallet operations, publishing private material, or modifying the running wallet workbench.
